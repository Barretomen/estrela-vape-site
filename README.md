# Estrela Vape Shop

Site estático de uma página para a Estrela Vape Shop, em Viseu e Matosinhos.

Inclui catálogo visual, contactos, horário com estado aberto/fechado e confirmação de idade. Foi feito com HTML, CSS e JavaScript, sem processo de build.

Para testar, abra `index.html` no navegador.

O horário é definido em `script.js` e também aparece na tabela de `index.html`; ao alterá-lo, atualize os dois locais.
