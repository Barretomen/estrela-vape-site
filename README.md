# Estrela Vape Shop — Site estático

Site de uma página para a Estrela Vape Shop, feito com HTML, CSS e JavaScript puro.

## Como abrir

1. Descompacta o ZIP.
2. Abre o arquivo `index.html` no navegador.
3. Para publicar, envia todos os arquivos para o teu alojamento/hosting mantendo a pasta `assets` junto do `index.html`.

## O que está incluído

- Layout responsivo para PC e telemóvel.
- CSS com sombras, animações, glass effect, hover e transições fluidas.
- Age gate 18+.
- Galeria separada por Máquinas, Líquidos e Loja.
- Tabela de horário com estado automático Aberto/Fechado.
- Detecção por fuso horário `Europe/Lisbon`.
- Feriados nacionais portugueses fixos + Sexta-feira Santa + Corpo de Deus.
- Contactos: telefone, email, Instagram e Facebook.

## Horário usado

Usei o horário em português/screenshot:

- Segunda a Sexta: 12:30 às 20:00
- Sábado: 14:00 às 19:00
- Domingo e feriados: fechado

Na mensagem havia também um horário em inglês diferente. Para trocar, edita o objeto `schedule` dentro de `script.js` e a tabela dentro de `index.html`.

## Observação legal

Por ser uma loja de vape/nicotina, o site inclui aviso 18+ e aviso de dependência. Mantém estes avisos ao publicar.
